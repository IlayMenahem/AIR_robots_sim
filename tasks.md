Independent Research Project
In this final stage, you will apply the concepts learned throughout the course to design and implement a robotic task planning project. The focus is on developing a complete robotic solution that demonstrates your understanding of task planning, motion planning, and robot control. You are not required to implement, but highly encouraged.

Project Requirements:
Choose an environment: Simulation environment ,or Lab robots
Task Planning Components:
  Task Definition
  - [X] Clear description of the chosen task
  - [X] Identification of constraints and challenges
  Task Decomposition
  - [X] Break down the complex task into basic operations
  - [X] Identify the critical path and potential bottlenecks
  Motion Planning Strategy
  - [X] Design movement sequences
  - [X] Consider obstacle avoidance
  Implementation Plan
  - [X] Develop modular code structure (pseudo code is sufficient)
  - [X] Include error handling and recovery
  - [X] Define success criteria
